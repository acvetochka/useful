# Анонімізація даних

## **Що таке анонімізація даних?**

Ви вже дізналися про важливість конфіденційності в аналітиці даних. Тепер настав час поговорити про **анонімізацію** даних і про те, які типи даних слід анонімізувати.**Персональні** дані ( **PII**) - це інформація, яка може бути використана сама по собі або в поєднанні з іншими даними для відстеження особи людини.

Анонімізація даних - це процес захисту приватних або конфіденційних даних людей шляхом видалення такої інформації. Як правило, анонімізація даних передбачає видалення, хешування або маскування особистої інформації, часто за допомогою кодів фіксованої довжини для представлення стовпців даних або приховування даних зі зміненими значеннями.

### **Ваша роль в анонімізації даних**

Організації зобов'язані захищати свої дані та особисту інформацію, яку вони можуть містити. Як аналітик даних, ви повинні розуміти, які дані потрібно анонімізувати, але зазвичай ви не несете відповідальності за саму анонімізацію даних. Рідкісним винятком може бути ситуація, коли ви працюєте з копією даних для тестування або розробки. У цьому випадку від вас можуть вимагати анонімізувати дані перед початком роботи з ними.

## **Які типи даних слід анонімізувати?**

Медичні та фінансові дані є одними з найбільш чутливих типів даних. Ці галузі дуже покладаються на методи анонімізації даних. Адже ставки дуже високі. Ось чому дані в цих двох галузях зазвичай проходять через **деідентифікацію**- **процес, який використовується для очищення даних від усієї інформації, що ідентифікує особ**у.

Анонімізація даних використовується практично в кожній галузі. Ось чому для аналітиків даних так важливо розуміти її основи. Ось список даних, які найчастіше анонімізуються:

- Номери телефонів
- Імена
- Номерні знаки та ліцензійні номери
- Номери соціального страхування
- IP-адреси
- Медичні записи
- Адреси електронної пошти
- Фотографії
- Номери рахунків

Для деяких людей просто має сенс анонімізувати цей тип даних. Для інших ми повинні дуже чітко визначити, що саме потрібно анонімізувати. Уявіть собі світ, де ми всі мали б доступ до адрес, номерів рахунків та іншої інформації, що дозволяє ідентифікувати особу. Це було б вторгненням у приватне життя багатьох людей і зробило б світ менш безпечним. Анонімізація даних - це один із способів зберегти конфіденційність і безпеку даних!
