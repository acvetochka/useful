# Ресурси для відкритих даних

На щастя для аналітиків даних, існує багато надійних ресурсів, що працюють з відкритими даними. Важливо пам'ятати, що навіть надійні дані потребують постійної оцінки, але ці веб-сайти є корисною відправною точкою:

1. <u>[**Сайт урядових даних США**](https://www.data.gov/)</u>: Data.gov - одне з найповніших джерел даних у США. Цей ресурс надає користувачам дані та інструменти, необхідні для проведення досліджень, і навіть допомагає їм розробляти веб- і мобільні додатки та створювати візуалізації даних.
2. <u>[**Бюро перепису населення США**](https://www.census.gov/data.html)</u>: Це джерело відкритих даних пропонує демографічну інформацію від федеральних органів влади, органів влади штатів і місцевих органів влади, а також комерційних організацій у США.
3. <u>[**Мережа відкритих даних**](https://www.opendatanetwork.com/)</u>: Це джерело даних має дійсно потужну пошукову систему та розширені фільтри. Тут ви можете знайти дані на такі теми, як фінанси, громадська безпека, інфраструктура, житло та розвиток.
4. <u>[**Google Cloud Public Datasets**](https://cloud.google.com/datasets)</u>: Існує низка публічних наборів даних, доступних через програму Google Cloud Public Dataset Program, які ви можете знайти вже завантаженими у BigQuery.
5. <u>[**Пошук наборів даних</u>:**](https://datasetsearch.research.google.com/) Dataset Search - це пошукова система, розроблена спеціально для наборів даних; ви можете використовувати її для пошуку конкретних наборів даних.
