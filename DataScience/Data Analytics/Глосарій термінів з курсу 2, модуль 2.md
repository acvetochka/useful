# **Терміни та визначення для курсу 2, модуль 2**

**Алгоритм:** Процес або набір правил, яких дотримуються для виконання певного завдання

**Великі дані:** Великі, складні набори даних, що зазвичай охоплюють тривалі періоди часу, які дозволяють аналітикам даних вирішувати далекосяжні бізнес-проблеми

**Інформаційна панель:** Інструмент, який відстежує вхідні дані в реальному часі

**Прийняття рішень на основі даних:** Процес вивчення різних джерел даних, щоб з'ясувати, що між ними є спільного

**Метрика:** Єдиний тип даних, що піддається кількісній оцінці та використовується для вимірювання

**Метрична ціль:** вимірювана ціль, встановлена компанією та оцінена за допомогою метрик

**Зведена діаграма:** Діаграма, створена на основі полів зведеної таблиці

**Зведена таблиця:** Інструмент узагальнення даних, який використовується для сортування, реорганізації, групування, підрахунку, підсумовування або усереднення даних

**Типи проблем:** Різні проблеми, з якими стикаються аналітики даних, включаючи категоризацію речей, виявлення зв'язків, пошук закономірностей, визначення тем, прогнозування та виявлення чогось незвичайного

**Якісні дані:** Суб'єктивна та пояснювальна міра якості або характеристики

**Кількісні дані:** Конкретна та об'єктивна міра, така як число, кількість або діапазон

**Звіт:** Статичний збір даних, який періодично надається зацікавленим сторонам

**Рентабельність інвестицій (ROI):** Формула, яка використовує показники інвестицій та прибутку для оцінки успішності інвестицій

**Дохід:** Загальна сума доходу, отримана від продажу товарів чи послуг

**Невеликі дані:** Невеликі, конкретні дані, зазвичай за короткий проміжок часу, які є корисними для прийняття повсякденних рішень
